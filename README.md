# My Shop Manager — Dukan Management (React Edition)

A web application for Pakistani sole proprietors, general stores, and specialized retailers to track shop records, monitor estimated business profits, and prepare annual tax reports for FBR IRIS review.

## Key Features

- **Bilingual Interface**: Seamless toggle between English and Urdu (اردو).
- **Store Mode Setup**: Choose between Simple Retail / General Store and Specialized Store.
- **Financial Record Tracking**: Record and edit 13 on-device financial fields including sales, purchases, business expenses, cash in hand, bank/wallet balance, stock, customer credit (udhaar), supplier payables, business assets, loans, personal expenses, other income, and tax paid/deducted.
- **Dashboard**: Real-time overview featuring estimated business profit, quick financial metrics, today's record launcher, and tax filing readiness guidance.
- **Annual Tax Preparation Report**: Categorized tax report covering business income, assets & liabilities, and tax reconciliation for review before entry into FBR IRIS.
- **Local Persistence**: Data is saved in client-side storage on the device.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.
